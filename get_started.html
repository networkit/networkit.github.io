Get Started¶

Take a look at Installation or Build NetworKit from Source in order to install NetworKit as a Python3 package or directly build it from source.

With NetworKit as a Python extension module, you get access to native high-performance code and can at the same time work interactively in the Python ecosystem. Although the standard Python interpreter works fine, we recommend IPython as a great environment for scientific workflows. View the IPython Quickstart Guide for installation instructions and how to use NetworKit with IPython.

Once you have installed NetworKit, please make sure to check out our NetworKit UserGuide for an overview of the features provided in NetworKit.

Installation¶

Requirements¶

NetworKit ships as a prebuilt package for Linux, macOS and Windows. To install it, you only need Python 3.10 or higher. You do not need a compiler. The following package managers provide NetworKit:

Package manager

Python module

C++ core library only

pip

pip install networkit

–

conda

conda install -c conda-forge networkit

conda install -c conda-forge libnetworkit

brew

brew install networkit

brew install libnetworkit

spack

spack install py-networkit

spack install libnetworkit

If you want the most recent development version, you can install a nightly build. We publish it on the networkit-nightly channel after each push to the master branch:

pip install --upgrade --extra-index-url https://pypi.anaconda.org/networkit-nightly/simple networkit-nightly

Linux¶

On Linux, pip is the most common way to install NetworKit. Recent Debian and Ubuntu releases do not let pip install packages into the system Python. We therefore recommend a virtual environment:

# Install Python3 with the venv module (Debian/Ubuntu)
sudo apt install python3 python3-venv

# Create and activate a virtual environment
python3 -m venv ~/networkit-env
source ~/networkit-env/bin/activate

# And finally ... install NetworKit
pip install networkit

macOS¶

On macOS, we recommend brew for managing NetworKit installations. The brew formula handles all dependencies.

# Install Homebrew (if needed)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Install NetworKit via brew
brew install networkit

Alternatively, you can install NetworKit with pip in a virtual environment, as shown for Linux.

Windows¶

On Windows, first install the official Python package. Then install NetworKit from a command prompt:

pip install networkit

You can also use the Windows Subsystem for Linux (WSL). Inside WSL, follow the instructions for Linux.

Build NetworKit from Source¶

You can clone NetworKit from GitHub with git. To build NetworKit from source, you need the following software:

  • A modern C++ compiler, e.g.: g++ (>= 10.0), clang++ (>= 11.0) or MSVC (>= 14.30)

  • OpenMP for parallelism (usually ships with the compiler)

  • Python3 (3.10 or higher is supported)

    • Development libraries for Python3. The package name depends on your distribution. Examples:

      • Debian/Ubuntu: apt-get install python3-dev

      • RHEL/CentOS: dnf install python3-devel

  • Pip

  • CMake version 3.6 or higher (e.g., pip install cmake)

  • Build System: Make or Ninja

  • Cython (e.g., pip install cython)

On Windows, the build needs the free Community Edition of Visual Studio or higher. The build must be able to find the MSVC compiler (cl.exe). One way to achieve this is to start the build from the “Native Tools Command Prompt” that Visual Studio provides.

For the build steps, we refer to the README file of our GitHub repository.

Use NetworKit with IPython¶

First make sure you have installed IPython, e.g. via pip: pip install ipython.

IPython Terminal¶

If you want to use NetworKit in the IPython terminal, type the following commands in your OS terminal:

ipython

from networkit import *

The first line opens the IPython terminal. The second line imports the networkit Python module. After that, you should be able to use NetworKit interactively. For usage examples, refer to the NetworKit UserGuide.

Jupyter Notebook¶

Additionally, we recommend that you familiarize yourself with NetworKit through experimenting with the interactive notebook User-Guide.ipynb. It is located in the folder notebooks of the NetworKit repository. The user guide introduces a large portion of NetworKit’s functionality with usage examples. The same folder holds further notebooks on specific topics, such as centrality, community detection and graph generators. To display and work with these notebooks, you have to install Jupyter and start a local notebook server from the terminal with:

pip install notebook
jupyter notebook

If you run into any problems with Jupyter, head over to the Jupyter documentation. If the notebook server starts as it is supposed to, your default browser should open a web interface. Otherwise, open it manually. Then open User-Guide.ipynb from the folder notebooks.

To show plots within the notebooks, place the following two lines at the beginning of your notebook:

%matplotlib inline
import matplotlib.pyplot as plt

Known Issues¶

  • Some algorithms (e.g. StronglyConnectedComponents) are implemented in a recursive manner and for large input may exceed the default stack size on your platform. To work around this issue, you can lift the stack size limit for your terminal process and subsequent child processes with ulimit -s unlimited or ulimit -Hs (to the hard limit if there is one). It is also possible to change resource limits from Python directly with import resource; resource.setrlimit(resource.RLIMIT_STACK, (-1, -1)).

  • On macOS, it can happen that the g++ compiler is unable to locate specific Linux-based header files. An example would be an error during the compilation of a C++ header which includes stdint. This can generate the following error message: fatal error: sys/_types/_int8_t.h: No such file or directory. This error will most likely happen on new systems or after a major system upgrade. In this case you need to (again) install the Xcode command line tools: xcode-select --install. Afterwards the code should compile completely.
